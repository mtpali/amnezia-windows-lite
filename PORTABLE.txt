WINDOWS LITE

Extract the ZIP to a local folder and run WindowsLite.exe. Accept the Administrator prompt. Keep wintun.dll next to the EXE. No MSI or setup is needed.

Import .conf files or a configuration ZIP, select a configuration and click Connect. Double-click a configuration to connect/disconnect. The last successful connection is remembered. It is selected next time; it is not automatically connected.

Close hides the window to the tray. Use Exit in the tray menu to disconnect tunnels and remove the temporary WindowsLite services. Exit before moving or deleting the application folder. Services are demand-start and do not start at boot.

Data contains SYSTEM-encrypted configuration files. State contains the remembered selection. Both stay next to the EXE. Configurations use Windows DPAPI, so export them before transferring them to a different Windows installation. Exported configuration ZIPs include private keys.

Block untunneled traffic is OFF for standard imported configurations, including 0.0.0.0/0 and ::/0 routes. Routing stays unchanged. It can be enabled explicitly in Edit. This local option is stored as BlockUntunneledTraffic = on and is not sent to the protocol engine. Remove that line when exporting an opted-in configuration to another client.

The interface is OLED black only. The About page, promotional text and upstream updater have been removed. Logs are available on demand. Native file pickers use Windows common dialogs.

amd64: Windows 10/11 x64. arm64: Windows 11 ARM64. Windows 7 is not supported.
